# 競走馬キャリアサイクル（4週間育成＆殿堂入り）仕様書

本ドキュメントは、「TurfTalk」における競走馬の4週間キャリアサイクル（新馬デビューから海外G1ラストラン・引退・殿堂入り、そして次世代への継承）の機能仕様を定めます。

---

## 1. 背景と目的

* **マンネリ防止と明確なゴール（締め切り効果）:**  
  1頭の馬を永遠に担当し続けるのではなく、「4週間（1ヶ月）で1世代」という短期的なマイルストーンを設けることで、英語学習の継続率（完走率）を劇的に向上させる。
* **競馬の美学（引退・血統・世代の継承）の再現:**  
  競馬ファンの情緒（名馬の引退式、次世代へのバトンタッチ）を体験可能にし、単なるクイズアプリを超えた愛着を形成する。
* **単語帳・アチーブメントの資産化:**  
  引退した馬を「殿堂入りカード」としてアーカイブし、「この馬と一緒にマスターした英語フレーズ数」をコレクション要素として可視化する。

---

## 2. 4週間キャリアプラン（1世代のローテーション）

1頭の競走馬は **4つのキャリアステージ（Week 1〜4）** を駆け抜け、最後のレース後に感動の引退式を迎えます。

| ステージ | キャリア段階 | 学習テーマ | 週末の模擬レース | レース条件・演出 |
| :---: | :--- | :--- | :--- | :--- |
| **Week 1** | **新馬・初陣** | ゲート・基本の手応え (`feel`) | 🔰 **メイクデビュー（新馬戦）** | 芝1600m。初陣の初々しさとゲート入りの緊張感。 |
| **Week 2** | **重賞挑戦・台頭** | 仕掛け・位置取り・展開 (`tactics`) | 🥈 **前哨戦トライアル (G2/G3)** | 芝2000m。本番を見据えたポジション争いと仕掛け。 |
| **Week 3** | **本格化・国内頂点** | 勝負根性・激しい叩き合い (`reaction`) | 🥇 **国内最高峰G1 (日本ダービー等)** | 芝2400m。直線の長い叩き合い、世代の頂点を決める一戦。 |
| **Week 4** | **世界挑戦・ラストラン** | 海外コメント・馬場適性 (`comment`) | 🏆 **世界最高峰G1 (凱旋門賞等)** | 芝2400m。世界最強の壁、タフな馬場、ラストランの誇り。<br>**➡ レース後、引退式・殿堂入り授与** |

---

## 3. 進行モデル（詰まり・離脱防止の安全設計）

英語初級者や多忙な社会人ペルソナが、多忙で数日〜数週間ログインできなかった場合でも挫折しないよう、以下の安全設計を徹底します。

1. **マイペース消化ベースの週送り:**
   - 平日調教を規定回数（例: 3〜5回）消化すると、その週の週末模擬レースへの出走権が解放される。
   - 週末レースを完走した時点で、次の週（Week 2など）へ進む。
   - ※「ログインしなかったから勝手に愛馬が引退・スキップされていた」という事態は絶対に発生させない。
2. **操作負担ゼロ（100%クイズ主役）:**
   - 育成シミュレーション特有の「パラメータ割り振り」「コマンド選択」などのゲーム的負荷は排除。
   - ユーザーは今まで通り「1日1〜2分（3問）のクイズを解くだけ」で、自動的に馬のストーリーが進む。

## 4. 引退式・殿堂入り（Hall of Fame）仕様

Week 4 の海外G1レース完了後、愛馬の引退セレモニー画面が表示されます。

### ① 殿堂入りカード（Hall of Fame Card）
引退馬は美麗な「殿堂入りデジタルカード」として永続化（LocalStorage）されます。
* **基本情報:** 馬名、毛色、世代番号（第何世代）、生涯戦績（例: 4戦3勝）
* **獲得タイトル:** G1勝利バッジ（例: 「凱旋門賞馬」「クラシック制覇」）
* **学習実績（アチーブメント）:** 
  - この馬の担当期間中に正解・マスターしたフレーズ数（例: 22 / 30語）
  - 愛馬に授与される二つ名・称号（例: 「剛脚の快速馬」「不屈のステイヤー」）

### ② 次世代へのバトンタッチ（新馬の命名・指名）
* 引退後、すぐに次の世代の新馬（第2世代）を担当。
* **血統ボーナス（継承インセンティブ）:**
  - 前世代で多くのフレーズをマスターしていた場合、次世代の新馬の初期調子が上がりやすい、あるいは限定の毛色が選べる等のささやかなご褒美を付与。

## 5. データモデル設計 (TypeScript Definition 案)

```typescript
export interface CareerRaceRecord {
  week: 1 | 2 | 3 | 4;
  raceName: string;
  grade: 'Maiden' | 'G2' | 'G1' | 'WorldG1';
  score: number;      // 0〜5問
  placementText: string; // "1着", "2着" 等
}

export interface CareerHorse {
  generation: number;            // 世代番号 (1, 2, ...)
  name: string;                  // 馬名
  color: '鹿毛' | '栗毛' | '芦毛' | '青毛';
  currentWeek: 1 | 2 | 3 | 4;    // 現在のキャリア週
  weight: number;                // 馬体重
  raceHistory: CareerRaceRecord[]; // 過去レース成績
  learnedPhraseIdsInCareer: string[]; // この馬の担当中に習得したフレーズID
}

export interface HallOfFameHorse {
  id: string;
  generation: number;
  name: string;
  color: string;
  retiredDate: string;           // YYYY-MM-DD
  totalRaces: number;            // 4戦固定
  wins: number;                  // 1着回数
  g1Titles: string[];            // 獲得G1タイトル一覧
  learnedCount: number;          // マスターしたフレーズ総数
  titleName: string;             // 授与された二つ名・称号
}
```
