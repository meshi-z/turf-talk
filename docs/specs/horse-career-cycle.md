# 競走馬キャリアサイクル（4週間育成＆殿堂入り）仕様書

本ドキュメントは、「TurfTalk」における競走馬の4週間キャリアサイクル（馬名自動生成・8大路線選択・週別レース進行・引退式・殿堂入り・データ保存方針）の機能仕様を定めます。

---

## 1. 背景と目的

* **明確なゴール（締め切り効果）と継続率の向上:**  
  1頭の馬を永遠に担当するのではなく、「4週間（1ヶ月）で1頭のキャリアを完走する」マイルストーンを設けることで、学習継続率を飛躍的に向上させる。
* **多様な競馬の魅力（8大路線の歩み）:**  
  3歳クラシックからスプリント、長距離ステイヤー、ダート、そして障害（ジャンプ）まで、多彩な路線を選択可能にし、路線ごとに異なる競馬英語（行き脚、折り合い、スタミナ、馬場適性など）を体験・習得可能にする。
* **愛着が湧く馬名生成 & 殿堂入りアーカイブ:**  
  名詞・形容詞の組み合わせによる自然な馬名生成（再生成可能）と、引退後の「殿堂入りカード」コレクション化。

---

## 2. 馬名生成システム (Horse Naming System)

新馬担当時に、ユーザーの入力負荷をなくしつつ愛着を持てるよう、単語リストからランダム生成する仕組みを導入します。

### ① 生成ロジック
* **組み合わせパターン:**
  - `[形容詞・冠名]` ＋ `[名詞]`（例: `Silent` + `Hero` = サイレントヒーロー、`Golden` + `Runner` = ゴールデンランナー）
  - `[名詞]` ＋ `[名詞]`（例: `Turf` + `Star` = ターフスター、`Thunder` + `Impact` = サンダーインパクト）
* **単語プール（例）:**
  - 前半（形容詞・冠名）: `Turf`, `Silent`, `Speedy`, `Grand`, `Golden`, `Mystic`, `Thunder`, `Noble`, `Brave`, `Iron`, `Cosmic`, `Shining`, `Royal`, `Wild`
  - 後半（名詞）: `Star`, `Hero`, `Runner`, `Shadow`, `King`, `Queen`, `Crown`, `Impact`, `Glory`, `Knight`, `Arrow`, `Bullet`, `Dancer`, `Meteor`

### ② ユーザーUI
* **🎲 再生成ボタン:** ボタンをタップするだけで、気に入る名前が出るまで何度でも瞬時に再生成可能。
* **✏️ 手動編集（カスタム）:** こだわりのある競馬ファンのため、直接テキスト入力で好きな愛馬名に変更することも可能。

## 3. 8大路線（キャリアローテーション）定義

ユーザーは新馬担当時に、歩ませたい **路線（全8パターン）** を1つ選択します。

### 路線別の出題テーマ連動
* **スプリント:** ゲート出足、行き脚（`travelling sweetly`）、一瞬のキレ（`put the race to bed`）
* **ステイヤー・中長距離:** 折り合い（`drop the bridle`）、スタミナ（`stayed the trip`）、底力（`dug deep`）
* **ダート・障害:** タフな馬場（`handle the ground`）、位置取り（`boxed in`）、粘り強さ（`kicked on`）

## 4. 進行モデル（マイペース消化型）

* **消化ベースの週送り:**
  - 平日調教を規定回数（例: 3〜5回）消化すると、その週の模擬レースへの出走権が解放。
  - 模擬レースを完走した時点で、次の週（Week 2など）へ移行。
  - **安心設計:** ユーザーが忙しくてログインできない週があっても、愛馬が勝手にスキップされたり強制引退されることはありません。自分のペースで確実に4週を完走できます。

---

## 5. 引退式・殿堂入り（Hall of Fame）

Week 4 の海外G1または大一番レース完走後、引退セレモニーが開催されます。

1. **殿堂入りカード（Hall of Fame Card）:**
   - 馬名、世代番号、選択した路線、生涯戦績（4戦の着順一覧）
   - 獲得タイトル（例: 「日本ダービー馬」「凱旋門賞馬」「世界最強スプリンター」）
   - **学習実績:** この馬と一緒にマスターした英語フレーズ数（例: 24 / 30語）
   - **二つ名・称号授与:** 戦績や成績に応じた称号（例: 「疾風の快速王」「不屈の長距離覇者」）
2. **次世代へのバトンタッチ:**
   - 引退完了後、次世代（第2世代…）の新馬選択へ遷移。
   - 前世代の学習実績に応じたささやかな血統ボーナス（初期調子アップ等）を付与。

## 6. データ保存（LocalStorage）と注意事項の設計方針

### ① 保存方針（Phase 1 〜 Phase 3）
* **LocalStorage 完結:**
  - 1頭あたりのキャリアデータ・殿堂入りデータは 1KB 未満。
  - 100頭殿堂入りしても 100KB 未満のため、ブラウザ容量（約5MB）に対し十分軽量に動作します。
* **サーバーレス運用のメリット:**
  - アカウント登録やパスワード管理が不要で、誰でも即座に完全無料で学習を開始できます。

### ② 注意事項の明記（UI上のアナウンス）
アプリ内の設定・フッター・利用規約画面（Issue #21）に、以下の注意事項を明記します：
> **【データ保存に関するご注意】**  
> 本アプリはアカウント登録不要でご利用いただけるよう、学習進捗および愛馬のデータをすべてお使いのブラウザ内（LocalStorage）に保存しています。  
> そのため、ブラウザの「閲覧履歴・Cookie・キャッシュの消去」を行ったり、シークレット（プライベート）モードで利用された場合、進捗データがリセットされますのでご注意ください。  
> ※ 機種変更時のバックアップ用データ書き出し/読み込み機能は順次追加予定です。

### ③ 将来のクラウド同期（Phase 4 / 将来構想）
* 「PCとスマホ間でのリアルタイム同期」や「他プレイヤーとの対戦・ランキング機能」が必要となった段階で、Firebase / Supabase 等の認証・DB基盤を導入。
* その際も、現在のデータモデルからクラウドDBへワンクリックで引き継げる移行ロジックを用意します。

## 7. データモデル設計 (TypeScript Definition)

```typescript
export type CareerRouteId =
  | 'classic-colt'   // 3歳牡馬クラシック
  | 'classic-filly'  // 3歳牝馬クラシック
  | 'sprint'         // 古馬短距離
  | 'middle'         // 古馬マイル・中距離
  | 'stayer'         // 古馬長距離
  | 'dirt-mile'      // ダート短中距離
  | 'dirt-classic'   // ダート王道中距離
  | 'jump';          // 障害

export interface CareerRouteInfo {
  id: CareerRouteId;
  name: string;
  categoryName: string;
  description: string;
  races: {
    week: 1 | 2 | 3 | 4;
    raceName: string;
    distanceText: string;
    surface: 'turf' | 'dirt' | 'jump';
    grade: 'Maiden' | 'G3' | 'G2' | 'G1' | 'WorldG1';
    themeCategory: 'feel' | 'tactics' | 'reaction' | 'comment';
  }[];
}

export interface CareerHorse {
  generation: number;            // 世代番号 (1, 2, ...)
  name: string;                  // 馬名
  color: '鹿毛' | '栗毛' | '芦毛' | '青毛';
  routeId: CareerRouteId;        // 選択した路線
  currentWeek: 1 | 2 | 3 | 4;    // 現在週
  weight: number;                // 馬体重
  raceHistory: {
    week: 1 | 2 | 3 | 4;
    raceName: string;
    score: number;
    placementText: string;
  }[];
  learnedPhraseIdsInCareer: string[]; // この馬の担当期間中に習得したフレーズID
}

export interface HallOfFameHorse {
  id: string;
  generation: number;
  name: string;
  color: string;
  routeId: CareerRouteId;
  routeName: string;
  retiredDate: string;           // YYYY-MM-DD
  wins: number;
  totalRaces: number;            // 4戦
  titles: string[];
  learnedCount: number;
  titleName: string;             // 二つ名
}
```
