# 競走馬キャリアサイクル（4週間育成＆殿堂入り）仕様書

本ドキュメントは、「TurfTalk」における競走馬の4週間キャリアサイクル（馬名自動生成・8大路線選択・週別レース進行・引退式・殿堂入り・データ保存方針）の機能仕様を定めます。

---

## 1. 背景と目的

* **明確なゴール（締め切り効果）と継続率の向上:**  
  1頭の馬を永遠に担当するのではなく、「4週間（1ヶ月）で1頭のキャリアを完走する」マイルストーンを設けることで、学習継続率を飛躍的に向上させる。
* **多様な競馬の魅力（8大路線の歩み）:**  
  3歳クラシックからスプリント、長距離ステイヤー、ダート、そして障害（ジャンプ）まで、多彩な路線を選択可能にし、路線ごとに異なる競馬英語（行き脚、折り合い、スタミナ、馬場適性など）を体験・習得可能にする。
* **愛着が湧く馬名生成 & 殿堂入りアーカイブ:**  
  名詞・形容詞の組み合わせによる自然な馬名生成（再生成可能）と、引退後の「殿堂入りカード」コレクション化。

---

## 2. 馬名生成システム (Horse Naming System)

新馬担当時に、ユーザーの入力負荷をなくしつつ愛着を持てるよう、単語リストからランダム生成する仕組みを導入します。

### ① 生成ロジックと単語選定ポリシー（セーフティ基準）
* **組み合わせパターン:**
  - `[形容詞・冠名]` ＋ `[名詞]`（例: `サイレント` + `ヒーロー` = サイレントヒーロー、`ゴールデン` + `ランナー` = ゴールデンランナー）
  - `[名詞]` ＋ `[名詞]`（例: `ターフ` + `スター` = ターフスター、`クリスタル` + `クラウン` = クリスタルクラウン）
  - JRAの馬名規定に準拠し、合算で **2〜9文字のカタカナ** に収まる組み合わせのみを選出（同一語重複は除外）。
* **セーフティ基準（穏当な単語プール）:**
  - 暴力・武器・薬物・アルコール・性的表現・ネガティブな連想を含む単語は一切排除し、自然現象・天体・宝石・音楽・栄光・気品・風・翼など、爽やかで品格のある単語のみで構成。
  - 前半ワード（20語）: `ターフ`, `サイレント`, `ゴールデン`, `グランド`, `ノーブル`, `ロイヤル`, `コスモ`, `シャイニー`, `ブライト`, `クリスタル`, `エメラルド`, `サンライズ`, `ウインド`, `シルバー`, `ステラ`, `アストラル`, `サファイア`, `ハッピー`, `メイプル`, `オーシャン`
  - 後半ワード（20語）: `スター`, `ヒーロー`, `ランナー`, `クラウン`, `グローリー`, `ダンス`, `メテオ`, `ウイング`, `ブリーズ`, `ドリーム`, `オーロラ`, `コンパス`, `マーチ`, `ステップ`, `ソング`, `リズム`, `フラッグ`, `ホープ`, `ライト`, `スカイ`

### ② ユーザーUI・同時抽選・初回調教ロック・入力セキュリティ
* **🎲 再生成（命名）ボタンと毛色同時抽選:**
  - ボタンをタップするだけで、馬名の自動生成（`generateRandomHorseName`）と同時に、毛色の重み付き抽選（`rollHorseCoatColor`）が実行され、気に入る馬名・毛色の組み合わせが出るまで何度でも再抽選可能。
* **🔒 初回調教開始による馬名・毛色・路線の確定ロック:**
  - 馬名の命名・手動編集およびキャリア路線の変更は **「初回調教を完了する前（`hasTrained === false`）」** までに限定。
  - 未調教時は愛馬カード内に「💡 調教を開始すると馬名・毛色・路線が確定します」と案内を表示。
  - 一度でも調教を完了すると `hasTrained: true` となり、世代交代（引退・次世代誕生）まで馬名・毛色・路線が確定・ロックされる。
* **✏️ 手動編集（カスタム）とサニタイズ:**
  - 直接テキスト入力で好きな愛馬名（最大18文字）に変更可能。
  - **XSS・インジェクション対策:** 入力値は NFKC 正規化および制御文字・双方向制御文字（`[\p{Cc}\p{Cf}]`）の除去を行った上で、カタカナ・ひらがな・漢字・英数字・スペースのみを許可するホワイトリスト検証を実施。HTMLタグ記号（`<`, `>`）やスクリプト構文文字を含む入力はバリデーションで拒否し、LocalStorage 復元時も無害化（サニタイズ）を強制する。

## 2.5 毛色（JRA基準の全8種類）と重み付き抽選

JRA「サラブレッド講座：毛色の種類」に準拠した **全8種類の毛色** を定義します。実際の出現率そのままでは白毛が極端に低くなるため、**白毛を最少の 1%** とし、現実のサラブレッドの毛色分布に合わせて傾斜をかけた重み付き抽選を行います。

| 毛色 | 読み | 出現確率 | 特徴 |
| :--- | :--- | :---: | :--- |
| **鹿毛** | かげ | **40%** | 最も一般的な基本毛色 |
| **栗毛** | くりげ | **22%** | 鹿毛に次いで多い華やかな毛色 |
| **黒鹿毛** | くろかげ | **16%** | 精悍な黒みを帯びた鹿毛 |
| **芦毛** | あしげ | **8%** | 人気・個性ともに高い灰〜白色系の毛色 |
| **青鹿毛** | あおかげ | **6%** | 全身が黒く目や鼻周りに褐色が残る毛色 |
| **青毛** | あおげ | **4%** | 漆黒の希少な毛色 |
| **栃栗毛** | とちくりげ | **3%** | 深みのある黒みがかった栗毛 |
| **白毛** | しろげ | **1%** | 最少の激レア毛色（1%） |

### 路線・週別の出題テーマ連動と実況演出（Issue #43）
* **週ごとのテーマ優先出題（`selectRaceQuestions`）:**
  - **Week 1（メイクデビュー・初陣）:** `feel`（手応え・感触）カテゴリを優先出題。初めての道中での折り合い・ハミ受け・手応えを中心とした実況演出。
  - **Week 2（重賞・トライアル前哨戦）:** `tactics`（仕掛け・展開）カテゴリを優先出題。位置取り・ペース判断・仕掛けのタイミングを中心とした実況演出。
  - **Week 3（国内G1・頂上決戦）:** `reaction`（勝負根性・反応）カテゴリを優先出題。大観衆の歓声・直線での反応・魂の追い比べを中心とした実況演出。
  - **Week 4（海外G1・世界挑戦ラストラン）:** `comment`（陣営コメント・総括）カテゴリを優先出題。世界の強豪との激闘・歴史的フィナーレを中心とした実況演出。
* **距離連動の動的残り距離表示とステージ別着順総評:**
  - 出走レースの距離（1200m〜7200m）に応じて、5展開それぞれの残り距離バッジ（例: 1600m戦なら `残り 1600m` → `1000m` → `600m` → `300m` → `100m`）を自動算出。
  - レース結果画面（`/race-result`）の着順タイトルおよび総評コメントも、Week 1（初陣快勝等）〜 Week 4（世界制覇等）のステージに合わせて動的に変化。

## 4. 進行モデル（マイペース消化型・週末1回出走制限）

* **消化ベースの週送り（7日制調教 & 週末1回出走制限）:**
  - 週間調教日数（0〜7日）を消化すると、その週の模擬レースで余力ボーナス（3〜4日: 余力1回、5〜7日: 余力2回）を発揮可能。
  - 週末レースへの出走は **「1つの週末（月曜午前4時始まりの論理週）につき1回のみ」** に制限され、1日でWeek 1〜Week 4を一気に進めることはできない。
  - 模擬レースを完走した時点で、戦績を記録し次の週（Week 2 → Week 3 → Week 4）へステップアップ。同週末内は「出走完了 🏁（次回出走は来週末）」となり、翌週月曜午前4時に出走制限および週間調教日数がリセットされる（レース出走完了後も土日分の坂路調教・復習は継続可能）。
  - **週末レース解放条件（初回調教完了の必須化・Issue #59）:**
    - 土日モードにおいて、愛馬が一度も調教を行っていない状態（`careerHorse.hasTrained === false`）では週末レース出走バナーはロック（出走不可）され、代わりに「🔒 週末レース出走 • ロック中」案内カードが表示される。
  - **週末世代交代時の新世代Week 1レース即時出走防止（来週末デビュー制御・Issue #61）:**
    - 土日にWeek 4レースを終えて世代交代した場合、先代の週末レース出走済みステータス（`hasCompletedWeeklyRace: true` および `lastRaceWeekMonday`）を新世代へ引き継ぐ。
    - これにより、誕生した新馬は当該週末の間「🌿 新馬入厩 • 来週末デビュー！」としてレース出走がブロックされ、坂路調教や命名・路線選択などの入厩準備期間として過ごす。
    - 翌週月曜午前4時（週替わり境界）を迎えると出走制限がリセットされ、平日調教ウィークを経て翌週末にWeek 1デビュー戦（5問）が解放される。
  - **安心設計:** ユーザーが忙しくてログインできない週があっても、愛馬が勝手にスキップされたり強制引退されることはありません。自分のペースで確実に4週を完走できます。

## 5. 引退式・殿堂入り（Hall of Fame）と世代交代（Issue #44）

Week 4 の海外G1または大一番レース完走後、レース結果画面の「`🌸 引退式セレモニーへ進む`」ボタン（またはホーム画面の引退式案内バナー）から引退式セレモニー画面（`RetirementScreen`）が開催されます。

1. **二つ名（称号）の自動授与（`determineHorseEpithet`）:**
   - 4週間の戦績（勝利数・合計スコア）および歩んだ路線（8大路線）に応じて、以下の優先順で称号が授与されます：
     - **4戦全勝（4勝）:** `不敗の世界覇者`
     - **Week 3（国内G1）＋ Week 4（世界頂上決戦）連覇:** 路線別の最高称号（`世界を翔ける至高の王者` / `華麗なる世界の女帝` / `電光石火の世界快速王` / `威風堂々たる中距離の皇帝` / `無尽蔵のワールドステイヤー` / `砂塵を切り裂く剛脚王` / `砂塵を統べる世界覇王` / `伝説のグランドジャンパー`）
     - **Week 4（世界頂上決戦）制覇:** `世界の頂に立つ名馬`
     - **Week 3（国内G1）制覇:** 路線別の国内王者称号（`栄光のクラシック覇者` / `ターフに咲く優駿の女王` / `疾風の快速王` / `盾を制した中距離の雄` / `不屈の長距離覇者` / `砂のマイル王` / `黄金のダート王者` / `不撓不屈の大障害王者`）
     - **1勝以上（新馬戦・前哨戦等）:** `ターフを沸かせた実力馬`
     - **未勝利・累計スコア12点以上（入着多数）:** `堅実無比の名バイプレイヤー`
     - **その他完走:** `ひたむきな挑戦者`
2. **引退記念プレート & 生涯戦績サマリー（`evaluateRetirementSummary`）:**
   - 馬名、世代番号、性別・毛色、歩んだ路線、授与された二つ名（称号）
   - 獲得タイトル一覧（1着を獲得したレースの「`{レース名} 制覇`」バッジ）および Week 1〜4 の出走履歴
   - **学習実績:** この馬と一緒にマスターした英語フレーズ数（`learnedPhraseIdsInCareer.length`）
3. **殿堂入り保存と次世代（第 N+1 世代）への世代交代（`retireAndSpawnNextGeneration`）:**
   - 引退する愛馬の記録を `HallOfFameHorse` として `UserProgress.hallOfFame` 配列へ永続保存（Phase 3 の殿堂入りギャラリー機能と直結）。
   - 引退式画面の下部で、次世代（`generation + 1`）の新馬の **馬名・毛色同時抽選（🎲 命名・毛色抽選）**、**馬名手動編集（✏️ 手動編集）**、**キャリア路線（全8路線）の選択** を行い、「`第{N+1}世代「{馬名}」の育成を始める`」ボタンで世代交代を完了。
   - **引き継ぐデータとリセットされるデータ:**
     - 引き継ぐデータ：ユーザーの連続学習ストリーク（`streakDays`）、にんじん所持数（`carrotCount`）、全体の習得済みフレーズ（`learnedPhraseIds` / `lapCount`）、殿堂入り履歴（`hallOfFame`）。
     - 新世代用に初期化されるデータ：`careerHorse`（`generation + 1`, `currentWeek: 1`, `weight: 484`, `hasTrained: false`, `raceHistory: []`, `learnedPhraseIdsInCareer: []`）、および新世代初陣に向けた出走可能状態へのリセット。

## 6. データ保存（LocalStorage）と注意事項の設計方針

### ① 保存方針（Phase 1 〜 Phase 3）
* **LocalStorage 完結:**
  - 1頭あたりのキャリアデータ・殿堂入りデータは 1KB 未満。
  - 100頭殿堂入りしても 100KB 未満のため、ブラウザ容量（約5MB）に対し十分軽量に動作します。
* **サーバーレス運用のメリット:**
  - アカウント登録やパスワード管理が不要で、誰でも即座に完全無料で学習を開始できます。

### ② 注意事項の明記（UI上のアナウンス）
アプリ内の設定・フッター・利用規約画面（Issue #21）に、以下の注意事項を明記します：
> **【データ保存に関するご注意】**  
> 本アプリはアカウント登録不要でご利用いただけるよう、学習進捗および愛馬のデータをすべてお使いのブラウザ内（LocalStorage）に保存しています。  
> そのため、ブラウザの「閲覧履歴・Cookie・キャッシュの消去」を行ったり、シークレット（プライベート）モードで利用された場合、進捗データがリセットされますのでご注意ください。  
> ※ 機種変更時のバックアップ用データ書き出し/読み込み機能は順次追加予定です。

### ③ 将来のクラウド同期（Phase 4 / 将来構想）
* 「PCとスマホ間でのリアルタイム同期」や「他プレイヤーとの対戦・ランキング機能」が必要となった段階で、Firebase / Supabase 等の認証・DB基盤を導入。
* その際も、現在のデータモデルからクラウドDBへワンクリックで引き継げる移行ロジックを用意します。
