# 競走馬キャリアサイクル（4週間育成＆殿堂入り）仕様書

本ドキュメントは、「TurfTalk」における競走馬の4週間キャリアサイクル（馬名自動生成・8大路線選択・週別レース進行・引退式・殿堂入り・データ保存方針）の機能仕様を定めます。

---

## 1. 背景と目的

* **明確なゴール（締め切り効果）と継続率の向上:**  
  1頭の馬を永遠に担当するのではなく、「4週間（1ヶ月）で1頭のキャリアを完走する」マイルストーンを設けることで、学習継続率を飛躍的に向上させる。
* **多様な競馬の魅力（8大路線の歩み）:**  
  3歳クラシックからスプリント、長距離ステイヤー、ダート、そして障害（ジャンプ）まで、多彩な路線を選択可能にし、路線ごとに異なる競馬英語（行き脚、折り合い、スタミナ、馬場適性など）を体験・習得可能にする。
* **愛着が湧く馬名生成 & 殿堂入りアーカイブ:**  
  名詞・形容詞の組み合わせによる自然な馬名生成（再生成可能）と、引退後の「殿堂入りカード」コレクション化。

---

## 2. 馬名生成システム (Horse Naming System)

新馬担当時に、ユーザーの入力負荷をなくしつつ愛着を持てるよう、単語リストからランダム生成する仕組みを導入します。

### ① 生成ロジックと単語選定ポリシー（セーフティ基準）
* **組み合わせパターン:**
  - `[形容詞・冠名]` ＋ `[名詞]`（例: `サイレント` + `ヒーロー` = サイレントヒーロー、`ゴールデン` + `ランナー` = ゴールデンランナー）
  - `[名詞]` ＋ `[名詞]`（例: `ターフ` + `スター` = ターフスター、`クリスタル` + `クラウン` = クリスタルクラウン）
  - JRAの馬名規定に準拠し、合算で **2〜9文字のカタカナ** に収まる組み合わせのみを選出（同一語重複は除外）。
* **セーフティ基準（穏当な単語プール）:**
  - 暴力・武器・薬物・アルコール・性的表現・ネガティブな連想を含む単語は一切排除し、自然現象・天体・宝石・音楽・栄光・気品・風・翼など、爽やかで品格のある単語のみで構成。
  - 前半ワード（20語）: `ターフ`, `サイレント`, `ゴールデン`, `グランド`, `ノーブル`, `ロイヤル`, `コスモ`, `シャイニー`, `ブライト`, `クリスタル`, `エメラルド`, `サンライズ`, `ウインド`, `シルバー`, `ステラ`, `アストラル`, `サファイア`, `ハッピー`, `メイプル`, `オーシャン`
  - 後半ワード（20語）: `スター`, `ヒーロー`, `ランナー`, `クラウン`, `グローリー`, `ダンス`, `メテオ`, `ウイング`, `ブリーズ`, `ドリーム`, `オーロラ`, `コンパス`, `マーチ`, `ステップ`, `ソング`, `リズム`, `フラッグ`, `ホープ`, `ライト`, `スカイ`

### ② ユーザーUI・同時抽選・初回調教ロック・入力セキュリティ
* **🎲 再生成（命名）ボタンと毛色同時抽選:**
  - ボタンをタップするだけで、馬名の自動生成（`generateRandomHorseName`）と同時に、毛色の重み付き抽選（`rollHorseCoatColor`）が実行され、気に入る馬名・毛色の組み合わせが出るまで何度でも再抽選可能。
* **🔒 初回調教開始による馬名・毛色・路線の確定ロック:**
  - 馬名の命名・手動編集およびキャリア路線の変更は **「初回調教を完了する前（`hasTrained === false`）」** までに限定。
  - 未調教時は愛馬カード内に「💡 調教を開始すると馬名・毛色・路線が確定します」と案内を表示。
  - 一度でも調教を完了すると `hasTrained: true` となり、世代交代（引退・次世代誕生）まで馬名・毛色・路線が確定・ロックされる。
* **✏️ 手動編集（カスタム）とサニタイズ:**
  - 直接テキスト入力で好きな愛馬名（最大18文字）に変更可能。
  - **XSS・インジェクション対策:** 入力値は NFKC 正規化および制御文字・双方向制御文字（`[\p{Cc}\p{Cf}]`）の除去を行った上で、カタカナ・ひらがな・漢字・英数字・スペースのみを許可するホワイトリスト検証を実施。HTMLタグ記号（`<`, `>`）やスクリプト構文文字を含む入力はバリデーションで拒否し、LocalStorage 復元時も無害化（サニタイズ）を強制する。

## 2.5 毛色（JRA基準の全8種類）と重み付き抽選

JRA「サラブレッド講座：毛色の種類」に準拠した **全8種類の毛色** を定義します。実際の出現率そのままでは白毛が極端に低くなるため、**白毛を最少の 1%** とし、現実のサラブレッドの毛色分布に合わせて傾斜をかけた重み付き抽選を行います。

| 毛色 | 読み | 出現確率 | 特徴 |
| :--- | :--- | :---: | :--- |
| **鹿毛** | かげ | **40%** | 最も一般的な基本毛色 |
| **栗毛** | くりげ | **22%** | 鹿毛に次いで多い華やかな毛色 |
| **黒鹿毛** | くろかげ | **16%** | 精悍な黒みを帯びた鹿毛 |
| **芦毛** | あしげ | **8%** | 人気・個性ともに高い灰〜白色系の毛色 |
| **青鹿毛** | あおかげ | **6%** | 全身が黒く目や鼻周りに褐色が残る毛色 |
| **青毛** | あおげ | **4%** | 漆黒の希少な毛色 |
| **栃栗毛** | とちくりげ | **3%** | 深みのある黒みがかった栗毛 |
| **白毛** | しろげ | **1%** | 最少の激レア毛色（1%） |

## 3. 8大路線（キャリアローテーション）定義

ユーザーは新馬担当時（初回調教前まで）に、担当馬カード上で歩ませたい **路線（全8パターン）** を選択できます。  
路線によって週末レースの舞台・距離・条件および学習テーマが変化します。

| # | 路線名 | 特徴・対象 | Week 1 (初陣) | Week 2 (前哨戦) | Week 3 (国内頂点) | Week 4 (世界挑戦・引退戦) |
| :-: | :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | **3歳牡馬クラシック路線** | 王道の中長距離芝 | メイクデビュー (芝1800m) | 弥生賞 (G2・芝2000m) | 日本ダービー (G1・芝2400m) | 凱旋門賞 (世界G1・芝2400m) |
| **2** | **3歳牝馬クラシック路線** | 華やかな牝馬三冠 | メイクデビュー (芝1600m) | チューリップ賞 (G2・芝1600m) | 優駿牝馬/オークス (G1・芝2400m) | オペラ賞 (世界牝馬G1・芝2000m) |

### 路線別の出題テーマ連動
* **スプリント:** ゲート出足、行き脚（`travelling sweetly`）、一瞬のキレ（`put the race to bed`）
* **ステイヤー・中長距離:** 折り合い（`drop the bridle`）、スタミナ（`stayed the trip`）、底力（`dug deep`）
* **ダート・障害:** タフな馬場（`handle the ground`）、位置取り（`boxed in`）、粘り強さ（`kicked on`）

## 4. 進行モデル（マイペース消化型）

* **消化ベースの週送り:**
  - 平日調教を規定回数（例: 3〜5回）消化すると、その週の模擬レースで余力ボーナスを発揮可能。
  - 模擬レースを完走した時点で、戦績を記録し次の週（Week 2 → Week 3 → Week 4）へステップアップ。
  - **安心設計:** ユーザーが忙しくてログインできない週があっても、愛馬が勝手にスキップされたり強制引退されることはありません。自分のペースで確実に4週を完走できます。

---

## 5. 引退式・殿堂入り（Hall of Fame）

Week 4 の海外G1または大一番レース完走後、引退セレモニーが開催されます。

1. **殿堂入りカード（Hall of Fame Card）:**
   - 馬名、世代番号、選択した路線、生涯戦績（4戦の着順一覧）
   - 獲得タイトル（例: 「日本ダービー馬」「凱旋門賞馬」「世界最強スプリンター」）
   - **学習実績:** この馬と一緒にマスターした英語フレーズ数（例: 24 / 30語）
   - **二つ名・称号授与:** 戦績や成績に応じた称号（例: 「疾風の快速王」「不屈の長距離覇者」）
2. **次世代へのバトンタッチ:**
   - 引退完了後、次世代（第2世代…）の新馬選択へ遷移。
   - 前世代の学習実績に応じたささやかな血統ボーナス（初期調子アップ等）を付与。

## 6. データ保存（LocalStorage）と注意事項の設計方針

### ① 保存方針（Phase 1 〜 Phase 3）
* **LocalStorage 完結:**
  - 1頭あたりのキャリアデータ・殿堂入りデータは 1KB 未満。
  - 100頭殿堂入りしても 100KB 未満のため、ブラウザ容量（約5MB）に対し十分軽量に動作します。
* **サーバーレス運用のメリット:**
  - アカウント登録やパスワード管理が不要で、誰でも即座に完全無料で学習を開始できます。

### ② 注意事項の明記（UI上のアナウンス）
アプリ内の設定・フッター・利用規約画面（Issue #21）に、以下の注意事項を明記します：
> **【データ保存に関するご注意】**  
> 本アプリはアカウント登録不要でご利用いただけるよう、学習進捗および愛馬のデータをすべてお使いのブラウザ内（LocalStorage）に保存しています。  
> そのため、ブラウザの「閲覧履歴・Cookie・キャッシュの消去」を行ったり、シークレット（プライベート）モードで利用された場合、進捗データがリセットされますのでご注意ください。  
> ※ 機種変更時のバックアップ用データ書き出し/読み込み機能は順次追加予定です。

### ③ 将来のクラウド同期（Phase 4 / 将来構想）
* 「PCとスマホ間でのリアルタイム同期」や「他プレイヤーとの対戦・ランキング機能」が必要となった段階で、Firebase / Supabase 等の認証・DB基盤を導入。
* その際も、現在のデータモデルからクラウドDBへワンクリックで引き継げる移行ロジックを用意します。

## 7. データモデル設計 (TypeScript Definition)

```typescript
export type CareerWeek = 1 | 2 | 3 | 4;

export type HorseCoatColor =
  | '鹿毛'
  | '栗毛'
  | '黒鹿毛'
  | '芦毛'
  | '青鹿毛'
  | '青毛'
  | '栃栗毛'
  | '白毛';

export type CareerRouteId =
  | 'classic-colt'   // 3歳牡馬クラシック
  | 'classic-filly'  // 3歳牝馬クラシック
  | 'sprint'         // 古馬短距離
  | 'middle'         // 古馬マイル・中距離
  | 'stayer'         // 古馬長距離
  | 'dirt-mile'      // ダート短中距離
  | 'dirt-classic'   // ダート王道中距離
  | 'jump';          // 障害

export interface CareerRouteInfo {
  id: CareerRouteId;
  name: string;
  shortName: string;
  categoryName: string;
  sexAgeLabel: string;
  description: string;
  races: readonly {
    week: CareerWeek;
    raceName: string;
    distanceText: string;
    surface: 'turf' | 'dirt' | 'jump';
    grade: 'Maiden' | 'G3' | 'G2' | 'G1' | 'WorldG1';
    themeCategory: 'feel' | 'tactics' | 'reaction' | 'comment';
  }[];
}

export interface CareerRaceRecord {
  week: CareerWeek;
  raceName: string;
  score: number;
  placementText: string;
}

export interface CareerHorse {
  generation: number;                 // 世代番号 (1, 2, ...)
  name: string;                       // 馬名
  color: HorseCoatColor;              // 毛色 (8種類)
  routeId: CareerRouteId;             // 選択した路線
  currentWeek: CareerWeek;            // 現在週 (1〜4)
  weight: number;                     // 馬体重
  hasTrained: boolean;                // 初回調教実施済みフラグ（trueで馬名・毛色・路線をロック）
  raceHistory: CareerRaceRecord[];    // 出走戦績履歴
  learnedPhraseIdsInCareer: string[]; // この馬の担当期間中に習得したフレーズID
}

export interface HallOfFameHorse {
  id: string;
  generation: number;
  name: string;
  color: HorseCoatColor;
  routeId: CareerRouteId;
  routeName: string;
  retiredDate: string;           // YYYY-MM-DD
  wins: number;
  totalRaces: number;            // 4戦
  titles: string[];
  learnedCount: number;
  titleName: string;             // 二つ名
}
```
