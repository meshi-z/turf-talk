# 競走馬ビジュアル・イラスト素材制作仕様書

本ドキュメントは、「TurfTalk」に登場する競走馬（サラブレッド）のイラストおよびアニメーション素材の制作基準、全6シーンの仕様、アニメーション座標ロック要件、およびJRA基準の全8毛色カラーパレット・領域変換ルールを定めます。

---

## 1. 基本アートスタイルと解剖学・表現原則

1. **画風（フラット・2トーン・セルシェード）**:
   - 平日調教アニメーションの馬をベース原画とした、シャープな黒主線（`#14110F`）とフラットな2トーン塗り（明るいベース被毛＋奥の脚や腹下のシャドウ被毛）に統一する。
   - すべてのシーンにおいて **騎手は描かず（馬のみ）**、馬自身の躍動感と表情を主役とする。
2. **馬の瞳の表現（白目・強膜の排除）**:
   - 人間のように白目（強膜）が大きく見える表現は避け、実際のサラブレッドに即した **黒目（濃い暗褐色〜黒）100%のアーモンドアイ** に統一する。
3. **顔の向き（セリ・顕彰馬基準とコース進行基準の使い分け）**:
   - **① 公式立ち絵（ホーム画面・ステータスカード）のみ「左向き（頭が左・尾が右）」**: セリ（競り市）の上場写真やJRA顕彰馬の公式立ち写真における伝統的な立ち姿に準拠する。
   - **②〜⑤の調教・レース・結果シーンはすべて「右向き（頭が右・尾が左）」**: 画面左から右へ進行するコース演出および達成・結果表現として統一する。
4. **解剖学的正確性と脚の本数・交差管理**:
   - エドワード・マイブリッジ（Eadweard Muybridge）の『動く馬（The Horse in Motion）』等の襲歩（ギャロップ）連続写真を基準とし、6コマすべてで必ず4本脚（左前・右前・左後・右後）の骨格・関節構造を維持する（3本脚や5本脚にならないこと）。
   - 手前の脚（前景脚）は **ベース被毛色**、奥の脚（背景脚）は **シャドウ被毛色** で塗り分け、脚同士の重なりと前後関係を明確にする。

## 3. アニメーション品質基準（② 平日調教 / ④ 週末レース）

### ① 上下・前後ブレ防止の「3点座標ロック」
6コマ（各セル `500 × 360 px`）を連続再生した際に馬体がガクガクと上下・前後に揺れる現象を防ぐため、全6コマのすべてにおいて胴体の基準3点を以下のピクセル座標に厳密に一致させます。

| 基準点 | セル内座標 (`500 × 360 px`) | 比率 | 計測定義 |
| :--- | :---: | :---: | :--- |
| **背中の高さ (`BackY`)** | **`Y = 100.0 px`** | `27.78%` | 鞍の直後〜腰（`X = 165..185`）における背中の上端輪郭Y座標 |
| **肩の位置 (`ShoulderX`)** | **`X = 300.4 px`** | `60.08%` | ゼッケン前端・肩のライン（`Y = 100..140`）のX座標 |
| **胸の位置 (`ChestX`)** | **`X = 370.0 px`** | `74.00%` | 前胸の最も張り出した前端輪郭（`Y = 135..165`）のX座標 |

### ② 閉領域の背景透過とゼッケン・腹帯の保護
スプライトシート（JPEG）をCanvas等で透過処理してコース背景（坂路・ウッドチップ・芝）の上に描画する際、以下の透過・保護ルールを適用します。

1. **必ず背景を透過させる閉領域**:
   - 外周4辺からのフラッドフィル透過に加え、黒線で囲まれた以下の閉領域にも透過シードを配置し、アンチエイリアスの白灰色フチも含めて完全透過させる：
     - **頭・首・手綱の間の三角形空間**: セル内 `X: 365..420, Y: 85..120`
     - **交差する脚の間の閉空間**: セル内 `Y >= 180`（特に **3コマ目・4コマ目の交差する右後肢と左後肢の間の空間**）
2. **純白のまま100%保護する領域（② 平日調教アニメ）**:
   - **白ゼッケン内部（`X: 175..318, Y: 80..165`）**: 背景の白と混同して透過されないよう、外周フラッドフィルから隔離して純白（`#FFFFFF`）で塗りつぶす。
3. **腹帯（ガース）の完全保持**:
   - 鞍・ゼッケンから下へ伸びる黒い腹帯（`X: 268..304, Y: 145..206`）は、全6コマにおいて途中で途切れることなく **腹の下端輪郭線まで完全に繋がって胴体を巻いている状態** を維持する。

## 4. JRA基準の全8毛色カラーパレットと部位別変換ルール

### ① マスター原画からのプログラム領域変換アーキテクチャ
- **鹿毛（`bay`）の全6シーン** をマスター原画とし、各画像のピクセルを以下の5領域に分類した上で、毛色別のカラーパレットへプログラム変換（`.NET System.Drawing` スクリプト）します：
  1. **被毛領域（`Coat`）**: 明るいベース被毛（`BaseCoat`）と奥脚・腹下のシャドウ被毛（`ShadowCoat`）の2トーンを維持してパレット変換。
  2. **長毛領域（`Mane & Tail`）**: 前髪（耳の間）・たてがみ・尾。主線から `1.6〜2.2px` 内側を指定の `ManeTailFill` で塗装（うなじの頭絡ストラップ＝項革は黒のまま保護）。
  3. **下肢ソックス領域（`Lower Leg Stockings`）**:
     - `HasBlackStockings = true` の毛色（鹿毛・黒鹿毛・芦毛・青鹿毛・青毛）は、球節〜膝・飛節下のソックス領域を `StockingFill` で塗装。
     - `HasBlackStockings = false` の毛色（栗毛・栃栗毛・白毛）は、下肢の黒ソックスを解除し、手前の脚は `BaseCoat`、奥の脚は `ShadowCoat` で上肢とシームレスに連結（腹帯 `X: 268..304, Y: 145..206` および下方に茶色被毛が存在する上肢筋肉線は保護）。
  4. **蹄領域（`Hooves`）**: 接地部の蹄を毛色に応じた `HoofColor`（白毛はピンクがかった明るい飴色、栗毛は明るめの褐灰色、黒系は濃灰色）へ変換。
  5. **馬具・瞳保護領域（`Tack & Eye Protected`）**: 瞳（黒目）、頭絡、手綱、ハミ環、鞍、鐙、腹帯、白ゼッケン、濃紺ゼッケンと黄色い「`1`」は一切変色させず100%保護。
