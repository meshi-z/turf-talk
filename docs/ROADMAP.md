# 競馬英語学習アプリ ロードマップ & イテレーション計画

本プロジェクトは AI-DLC（AI-Driven Lifecycle）に基づき、段階的なプロトタイピングと価値検証を行いながら進めます。Version 1.0.0 を正式版（一般公開・実用ツール）のゴールと定義します。

---

## マイルストーン概要

| フェーズ | 対象バージョン | テーマ | 判定基準（Exit Criteria） |
| :--- | :--- | :--- | :--- |
| **Phase 1** | **v0.1.0 (Alpha)** | **MVP（最小検証版）** | 平日3問の解き心地・テンポ感・フレーズの納得感を開発者自身が確認できること |
| **Phase 2** | **v0.5.0 (Beta)** | **Core Loop（サイクルの確立）** | 「平日調教 → 週末レース出走」の1週間サイクルが自然に回ること |
| **Phase 3** | **v1.0.0 (Release)** | **Official Release（実用ツールの完成）** | 音声読み上げ・図鑑・PWAが揃い、日常的な観戦のお供として活用できること |

---

## 詳細フェーズ計画

### Phase 1: v0.1.0 (Alpha) - MVP
* **スコープ:**
  * [機能] 平日調教モード（1日3問固定・4択タップ式、日付シードによる日替わりローテーション・選択肢ランダムシャッフル）
  * [データ] 初期フレーズマスター（30問完了：手応え・仕掛け・勝負根性・コメント）
  * [演出] 正解/不正解判定（マイクロインタラクション・シェイク/ポップ）＋Web Audio API による効果音（SE・消音対応）＋「調教済」スタンプ押印アニメーション＆波紋演出＋進捗プログレス表示
  * [ストレージ・ロジック] LocalStorage（当日の完了フラグ、連続日数ストリーク、履修済みフレーズID、周回数、消音設定を記録）＋ 午前4時（28時）更新ロジックおよび連続学習日数追跡（Issue #36完了：v0.4.1）
  * [UI] 画面最下部へのフッターおよびアプリバージョン情報の表示
* **非スコープ:** 週末レースの複雑な判定、図鑑一覧、音声読み上げ（TTS）、PWA

### Phase 2: v0.5.0 (Beta) - Core Loop
* **スコープ:**
  * [機能] 曜日判定と週末レースモード解放ロジックの実装（土日限定解放、7曜日デバッグ切り替え機能完了：v0.2.0）
  * [機能] 週末レースモードの実装（土日限定解放、実践クイズ5問、実況展開演出、成績着順判定、ファンファーレSE完了：v0.3.0）
  * [演出・機能] 平日の調教消化日数に応じたコンディション演出・調教ヒント（馬体重、調子アイコン ↗、不正解除外ヒント、レース後フィードバック完了：v0.4.0）
  * [機能・演出] レースヒント温存ボーナス「にんじん（ストリーク補填）」システムの実装（「愛馬の余力」温存還元、未受講日自動補填救済、にんじんSE完了：v0.5.0）
  * [機能] 履修済みフレーズの簡易履歴一覧
  * [機能] 競走馬キャリアサイクル（Week 1〜4 のステージ進行・レース変化・次世代への継承）
  * [データ] フレーズマスターの拡充（実戦レース実況・パドック・馬場適性等の全60問へ倍増完了：v0.5.2）
* **非スコープ:** 音声再生、高度な検索・フィルター

### Phase 3: v1.0.0 (Release) - Official Release
* **スコープ:**
  * [機能] 殿堂入り愛馬アーカイブ（Hall of Fame ギャラリー、世代ごとの戦績・習得フレーズ記録）
  * [機能] Web Speech API 等を活用した英語音声読み上げ（リスニング補助）
  * [機能] フレーズ図鑑機能（カテゴリ絞り込み、キーワード検索、パートナー馬表示）
  * [基盤] PWA（Progressive Web App）対応（ホーム画面追加、オフラインキャッシュ）
  * [UI/UX] レスポンシブ最適化、全体のデザインポリッシュ
